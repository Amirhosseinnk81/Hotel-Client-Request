{% comment %} The in-room television screen (Stage 3.4). Deliberately plain: no JavaScript, no web fonts, no build step. Hotel set-top boxes run old, slow browsers, and a screen that fails to render is worse than one that looks ordinary. It reloads itself with a meta refresh rather than polling. Sized for a television seen from a bed, not a phone held at arm's length: large type, high contrast, wide margins for overscan. The palette is the project's own (globals.css) — dark surface, bronze accent — but written out here, because this page must not depend on the Next.js build. {% endcomment %} اتاق {{ room_number }}
